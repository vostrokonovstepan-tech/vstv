# Трекер целей — Telegram Mini App

Личный трекер: одна большая цель → ежедневные задачи → прогресс и таймер.

- **Сегодня** — задачи на день, кольцо выполнения, серия, быстрый старт таймера
- **Цели** — список целей с прогрессом и дедлайнами
- **Прогресс** — серии, суммарное время, график за 2 недели, календарь активности
- Внутри цели — календарь активности за 13 недель и управление задачами

## Стек

Vite + React + TypeScript + Tailwind. Бэкенда нет.

Данные лежат в **Telegram CloudStorage** — Telegram сам синхронизирует их между
твоими устройствами. Вне Telegram (обычный браузер при разработке) приложение
автоматически падает на `localStorage`, так что всё работает и на десктопе.

## Локальный запуск

```bash
npm install
```

```bash
npm run dev
```

Откроется на `http://localhost:5173`. В обычном браузере всё работает, только
данные хранятся локально, а не в облаке Telegram.

## Проверить в самом Telegram

Telegram пускает в мини-ап только по HTTPS, поэтому localhost нужно пробросить
наружу туннелем:

```bash
npx cloudflared tunnel --url http://localhost:5173
```

Команда выведет адрес вида `https://что-то.trycloudflare.com`. Дальше:

1. Открой [@BotFather](https://t.me/BotFather) → `/mybots` → твой бот
2. **Bot Settings → Menu Button → Configure menu button**
3. Вставь адрес туннеля и задай подпись кнопки, например «Мои цели»
4. Открой бота в Telegram и нажми кнопку меню

Адрес туннеля меняется при каждом перезапуске — для постоянного использования
нужен деплой.

## Деплой на Vercel

```bash
npx vercel
```

Vercel сам определит Vite (`npm run build` → папка `dist`). После первого
деплоя закрепи прод-версию:

```bash
npx vercel --prod
```

Полученный адрес пропиши в BotFather вместо туннеля — тем же путём
**Bot Settings → Menu Button**.

Токен бота приложению не нужен: мини-ап работает целиком на клиенте и ничего не
отправляет боту. Токен понадобится, только если позже добавим напоминания.

## Как устроены данные

| Ключ | Что внутри |
| --- | --- |
| `v1_goals` | список целей |
| `v1_tasks` | список ежедневных задач |
| `v1_m_2026-08` | отметки и время за месяц, по одному ключу на месяц |
| `v1_timer` | запущенный таймер, чтобы он пережил перезагрузку |

Разбивка по месяцам не случайна: у CloudStorage лимит 4096 символов на
значение и 1024 ключа, так что месяц в одном ключе — это и запас по размеру, и
десятилетия истории по количеству ключей.

При старте поднимаются последние 12 месяцев — на них считаются серии и графики.

## Структура

```
src/
  lib/
    telegram.ts   обёртка над Telegram SDK (тема, haptics, кнопка «назад»)
    storage.ts    CloudStorage с фолбэком на localStorage и отложенной записью
    date.ts       даты, склонения, форматирование длительностей
    progress.ts   серии, проценты, ряды для графиков
    accents.ts    палитра целей
  components/     Ring, Heatmap, Sheet, TaskRow, TimerBar, формы
  screens/        Today, Goals, GoalDetail, Profile
  store.tsx       состояние приложения и персист
```
